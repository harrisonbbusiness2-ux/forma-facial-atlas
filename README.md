# Forma Facial Atlas

An educational reference atlas exploring male facial anatomy, proportions, and aesthetic measurements.

**Live reference:** https://formafacialatlas.net/

## Project status

This repository is the beginning of a portable, GitHub-managed implementation of Forma. The original site's complete source bundle and backend were not available through the saved site record, so this codebase is a clean reconstruction of the public-facing atlas experience—not a byte-for-byte export of the hosted site.

## Current implementation

- Responsive editorial-style landing page
- Searchable index of 27 facial features
- Linked topic selection and research panel
- Front and profile reference illustrations (schematic, not measured anatomy)
- Clear distinction between educational reference material and individualized assessment

## Run locally

No build tools are required. Open `index.html` in a browser, or serve the folder with any static file server.

## Important

The illustrations are schematic placeholders. They do not represent validated ideal proportions or diagnostic measurements. Do not use them for medical decisions.
